# 📊 Sales Dashboard — Power BI

## 📌 Project Overview

This project is an interactive **Sales Dashboard developed using Microsoft Power BI** to analyze sales performance across products, categories, states, customers, quantity, transactions, and profit.

The dashboard covers sales data for the period **2020–2022** and presents key business metrics through interactive visualizations and KPI cards.

The objective of this project is to transform sales data into meaningful business insights that can support data-driven decision-making.

---

## 🎯 Business Objective

The main objective of this dashboard is to provide a centralized view of sales performance and help answer questions such as:

* What is the overall sales performance?
* What is the total profit generated?
* Which products have the highest quantities?
* Which categories contribute most to sales?
* Which states generate the highest sales?
* How many transactions have been recorded?
* How can sales performance be monitored through key business KPIs?
